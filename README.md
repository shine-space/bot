# 星尘智能官网体验原型

这是一个围绕具身智能机器人产品展示构建的单页体验原型，重点验证视觉叙事、动效节奏、产品信息呈现与基础可用性。

## 目标用户与核心任务

目标用户包括首次了解星尘智能的潜在客户、行业合作伙伴、媒体与求职者。页面首先需要让用户快速理解“星尘智能是谁、在做什么”，随后通过沉浸式产品展示建立品牌与技术认知，并帮助有进一步意向的用户查看 T1、S1 的关键信息和找到咨询入口。设计优先保证三项核心任务：理解品牌定位、比较产品能力、形成进一步联系的意愿。

## 既有基础与重新设计范围

项目保留了既有页面中的 WebGL / GSAP 视觉运行时、部分场景结构以及基础媒体素材，对应 `bot.js` 和 `bot.css`。这些内容体量较大且已经压缩，因此没有将其包装成个人从零开发的成果，而是作为体验重构的技术基础保留。

在此基础上，我重新梳理了中文品牌内容与信息层级，设计并实现了产品信息卡、价格与行动入口、产品详情和本地视频播放流程、滚动产品背景、关于我们内容区、加载状态、背景音频反馈及未完成导航状态。视觉上重新统一了字体、间距、按钮状态、导航反馈、加载标识与动效衔接；交互上补充了键盘操作、焦点管理、减少动态效果支持和移动端适配；内容结构上增加了语义化标题、产品参数表、SEO 元数据与结构化数据。

## 设计与 Vibe Coding 过程

项目以“具身智能的未来感、精密感与生命力”为视觉方向，使用深色空间、紫色能量光效、沉浸式动效和克制的信息层级建立品牌氛围。我先围绕核心浏览路径搭建可运行原型，再在真实页面中连续校准加载节奏、内容层级、产品浏览、视频反馈和响应式表现。开发过程中尽量把每次探索收敛为明确的站点能力模块，并将新增界面层与既有视觉运行时分离，避免后续调整继续堆叠成无法追踪的临时覆盖。

## AI 如何参与

AI 主要用于加速代码结构分析、备选方案探索、重复性实现、SEO 与无障碍检查，以及跨资源问题的定位。比如它帮助对比 SVG 路径范围、WebM 透明画布和浏览器中的实际渲染盒，从而缩小加载图跳位问题的排查范围。产品目标、视觉方向、信息取舍、交互优先级和最终验收仍由我判断；AI 生成的代码不会直接视为完成结果，而需要通过源码检查和真实浏览器回归后才会保留。

## 如何发现并修复问题

我采用“真实体验观察 → 缩小问题范围 → 验证根因 → 回归检查”的方式迭代。以加载标识为例，最初观察到 SVG 占位图切换到 WebM 时产生尺寸和位置跳变。单纯调整外层 CSS 没有解决问题后，我继续检查两个资源的内在尺寸，发现 SVG 的原始 `viewBox` 包含大面积透明区域，而 WebM 也存在透明画布，元素盒居中并不代表可见图形居中。最终通过修正 SVG 可见区域、让两种资源共享同一容器，并在视频触发 `playing` 后再淡入，消除了切换跳变，同时保留加载失败回退。类似方法也用于检查对话框键盘操作、焦点返回、无效导航、控制台错误和资源加载状态。

## 当前限制与后续计划

当前版本仍是体验原型，而非完整商业官网：新闻、招聘与英文版入口尚未建设，咨询入口还没有连接真实表单或 CRM，产品信息和品牌素材仍需业务方最终确认；核心 WebGL / GSAP 运行时来自既有压缩代码，包体较大，可维护性和低性能设备表现仍有优化空间；移动端已做基础适配，但还需要更多真实机型、弱网和触控场景测试。

后续将优先完成咨询转化闭环和内容管理能力，补充真实数据埋点与用户测试；随后拆分或替换遗留运行时，优化首屏资源、低性能降级和缓存策略；最后完善新闻、招聘、英文版本及更完整的跨浏览器、无障碍和移动端验收。

## 运行

项目没有构建依赖，使用任意静态服务器打开 `site/` 即可：

```bash
python3 -m http.server 8000 --directory site
```

## 前端结构

- `site/index.html`：页面内容、语义结构与资源装配。
- `site/assets/css/bot.css`：保留的 WebGL / GSAP 视觉运行时样式。
- `site/assets/css/site.css`：产品界面、响应式、无障碍和加载体验的正式站点层。
- `site/assets/js/bot.js`：保留的 WebGL / GSAP 体验运行时。
- `site/assets/js/*.js`：按能力拆分的加载、音频、产品预览、关于页与无障碍增强。

保留运行时与站点层之间维持明确边界，避免直接修改压缩后的遗留代码；新增行为通过语义化 HTML、独立 CSS 分区和小型能力模块完成。

## 体验原则

- 首屏 SVG 标识与 WebM 动画共享同一媒体容器，并按动画实际可见区域校准，避免资源切换时跳位。
- 动画仅在视频真正进入 `playing` 状态后替换静态标识，加载失败时保留可用回退。
- 支持键盘焦点、对话框焦点管理、跳到主要内容、表格表头与减少动态效果偏好。
- 未完成入口明确显示为不可用状态，避免用无效链接制造虚假的产品闭环。
